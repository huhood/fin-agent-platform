# Fin Agent Platform

A full-stack AI automation platform built with FastAPI and React for finance, payments, and blockchain security.

一个面向金融、支付和区块链安全场景的 AI 自动化平台，也是一个持续迭代的全栈工程实践项目。

## Long-term Goals

- 创建和管理自动化任务
- 接入 AI Agent
- 支持区块链地址与交易风险分析
- 提供任务日志和告警
- 支持 Docker 部署

## Tech Stack

- Backend: Python, FastAPI
- Frontend: React, TypeScript
- Database: PostgreSQL（后续）
- Infrastructure: Docker（后续）
